# zyuapp

Small, focused macOS apps. Paste a command into Terminal to install.

### 🤖 AI Coding Tool
A desktop app for working with Claude Code and Codex.
```sh
curl -fsSL https://raw.githubusercontent.com/zyuapp/ai-coding-tool/main/install.sh | sh
```

### 📚 Books
Read EPUB, PDF, and comics on your Mac, and ask Claude about what you read.
```sh
curl -fsSL https://raw.githubusercontent.com/zyuapp/books/main/install.sh | sh
```

### 🎬 Cutline
A video editor that Claude edits for you.
```sh
curl -fsSL https://raw.githubusercontent.com/zyuapp/cutline/main/install.sh | sh
```

### 🎙️ Just Speak
Talk instead of typing, in any app. Works offline.
```sh
curl -fsSL https://raw.githubusercontent.com/zyuapp/just-speak/main/install.sh | sh
```

### 📝 Just Notes
Record meetings and get searchable transcripts. Everything stays on your Mac.
```sh
curl -fsSL https://raw.githubusercontent.com/zyuapp/just-notes/main/install.sh | sh
```
